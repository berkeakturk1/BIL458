Decimal to Octal Converter
This repository contains a simple Python script that converts a decimal number to its octal equivalent. The script reads a decimal number from the user, performs the conversion, and then prints the resulting octal value.

Requirements
Python 3.x

Code Overview
Input: The script takes a decimal number as input.
Conversion: It converts the decimal number to octal by repeatedly dividing by 8 and computing remainders.
Output: The resulting octal number is printed to the console.
